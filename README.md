# Live Local Translator｜本機直播翻譯

> 本專案大部分程式碼由 Codex 協助撰寫，再由作者實際檢查功能並提出修改方向。

專為沒有字幕的外語直播設計：直接在 Chrome 裡用本機 Whisper 做語音辨識、用本機模型翻譯，**不需要任何付費 API key**。支援 YouTube 播放器內字幕、聊天室翻譯，以及自訂專有名詞詞彙表。

目前版本：**0.4.3-preview（測試版）**。目前僅提供 Windows 安裝程式，Chrome 擴充功能需手動載入，尚未上架 Chrome Web Store。

## 0.4.3 更新：修正新電腦因缺少模型而無法暖機

現在第一次按下「載入／暖機模型」時，程式會自動下載目前選取但尚未安裝的 Whisper／LLM 模型，下載完成後再開始暖機。

- 下載時會顯示進度；按「釋放模型」可取消下載，已下載的部分會保留，下次可以接續。
- 已完整下載的模型不會重複下載。
- 若不想自動下載，可以在設定中關閉。
- 使用自訂模型資料夾的話，仍需自行匯入模型。


## 功能

- **無字幕直播辨識**：支援 Whisper Tiny、Base、Small、Medium、Large-v3 Turbo，可選擇多語模式或英日來源模式。
- **本機字幕翻譯**：可使用 Gemma、WebLLM 相容引擎或 Chrome 內建翻譯（Translator）。模型可以常駐，停止擷取後不會卸載，也能手動釋放。
- **YouTube 兩種播放模式**：「即時播放」與「延後同步」。延後同步會同時延後原始聲音（PCM）與畫面（暫存於記憶體），畫面最高 960×540／15fps。
- **字幕顯示**：每句譯文至少顯示 1.5 秒；講話較快時會往下堆疊，最多同時顯示三句，超過時會稍微排隊。停止、拖曳進度條或切換影片時會清空字幕。
- **聊天室翻譯**：可與字幕共用 LLM，或另外使用 Chrome 機器翻譯。英文／日文留言會自動分流、逐則翻譯；每分鐘最多接收 2,000 則，留言量超過每分鐘 100 則時建議改用機器翻譯。自訂表情符號名稱不會送去翻譯。
- **專有名詞詞彙表**：支援已核可（Approved）詞條、來源別名、辨識原文與譯文修正、匯入／匯出，以及字幕除錯對照。
- **模型管理**：一鍵下載、固定版本並以 SHA256 驗證、手動匯入、查看占用空間；使用中或下載中的模型會受到刪除保護。

## 系統需求與權限

- Windows 桌面版 Chrome，需開啟硬體加速並支援 WebGPU。
- 本機模型依選擇會占用數 GB 的硬碟空間與顯示記憶體（VRAM）。若有 16GB VRAM，可以先用預設設定，再依實際效果調整。
- Chrome 版本、顯示卡驅動程式，以及 Chrome 內建翻譯是否提供該語言的模型，都會影響能否使用，無法保證所有電腦都相容。

預設安裝在使用者資料夾，不需要管理員權限，也不綁定電腦、不需要產品序號。不過公司／學校的電腦管理政策或受保護的安裝路徑，仍可能導致無法安裝。

所有 AI 推論都在 Chrome 中執行；Windows Native Messaging host 只負責管理本機模型檔案與下載。只有第一次下載模型時需要連網，之後的音訊與待翻譯文字都不會傳送給付費 API 或模型供應商。

## 安裝與升級

1. 到本儲存庫的 **Releases** 下載 Setup，或下載安裝用 ZIP 解壓縮後執行 Setup。注意：GitHub 自動產生的 **Source code ZIP 不是安裝包**。
2. 預設安裝位置為 `%USERPROFILE%\LiveLocalTranslator`。
3. 在 Chrome 開啟 `chrome://extensions`，打開「開發人員模式」，點選「載入未封裝項目」，選擇安裝目錄中的 **extension** 資料夾（`manifest.json` 就在這個資料夾裡）。
4. 進入擴充功能設定頁，下載或匯入模型，儲存並暖機後，再回到直播分頁啟動翻譯。第一次使用建議先用較小的模型測試。
5. 若要讓聊天室使用英日機器翻譯：選擇「Chrome 本機機器翻譯」與「英／日自動」，依畫面提示分兩次點擊，分別準備英文與日文模型，最後儲存。

**升級**會沿用原本的安裝位置，並保留 `models` 與 `data`。完成後請在 Chrome 重新載入擴充功能，並重新整理影片頁與設定頁。

**移除**時可以選擇保留模型；Chrome 中的擴充功能需要另外手動移除。

## 預覽版限制

- 不保證能在一句話結束後一秒內顯示譯文；速度會受模型大小，以及字幕與聊天室共用運算資源影響。
- 聊天室2,000 則是每分鐘的接收上限，不代表每分鐘都能全部翻完。只會處理頁面上已載入的留言；過量、等待超過 15 秒或推論出錯的留言會直接略過。
- 「英／日自動」只是依照文字字形做簡單分流，並非完整的語言偵測。純漢字留言需要 Chrome 語言偵測器就緒才能判斷，無法確定時會略過；其他使用拉丁字母的語言可能被誤判為英文。同一則留言英日混雜時，不保證每個詞都會被翻到。
- 模型仍可能出現幻聽（辨識出不存在的內容）、漏譯或誤譯，詞彙表與人聲過濾只能減少、無法完全避免。Qwen 為中國來源的實驗性選項，使用前請先閱讀並確認設定頁的警語。
- YouTube 廣告、DRM 內容、原生子母畫面、網站改版，以及各種需登入的聊天室情境，都還沒有完整測試；延後同步模式會降低畫面解析度與幀率。
