# Live Local Translator｜本機直播翻譯

本專案的大部分程式碼由 Codex 協助完成，並由人工檢視功能、提出修改建議。

針對沒有字幕的外文直播，在 Chrome 內使用本機 Whisper 辨識與本機翻譯。提供 YouTube 播放器字幕、聊天室翻譯與專有名詞詞彙表，不需付費 API key。

目前版本：**0.4.2-preview（測試版）**。目前提供 Windows 安裝程式，Chrome 擴充功能須手動載入；尚未上架 Chrome Web Store。

## 功能

- 無字幕直播語音辨識：Whisper Tiny、Base、Small、Medium、Large-v3 Turbo，多語或英日來源模式。
- 本機字幕翻譯：Gemma、WebLLM 相容引擎，或 Chrome Translator；模型可常駐，停止擷取後保留，亦可手動釋放。
- YouTube 即時播放／延後同步兩種模式。延後模式同時延後原始 PCM 聲音與記憶體影格，畫面最高 960×540／15fps。
- 譯文實際顯示至少 1.5 秒；快句往下排列，最多同時顯示三句，超出時會短暫排隊。停止、拖曳或換片時清空。
- 聊天室可選共用 LLM 或獨立 Chrome 機翻；英／日自動逐則分流，每分鐘接收上限 2,000 則，超過 100 建議使用機翻；自訂表情名稱不送翻譯。
- Approved 專有名詞詞彙表、來源別名、辨識原文與譯文修正、匯入／匯出及字幕除錯對照。
- 模型一鍵下載、固定版本與 SHA256 驗證、匯入、用量清單及使用中／下載中刪除保護。

## 系統與權限

Windows 桌面版 Chrome、啟用硬體加速與可用 WebGPU；本機模型依選擇占用數 GB 硬碟與顯存。16GB 顯存可從設定預設開始，再依實測調整。Chrome 版本、GPU 驅動與內建翻譯語言模型供應會影響可用性，不能保證所有電腦皆相容。

預設安裝到使用者資料夾，不要求管理員權限、不綁定電腦、不需產品授權碼。公司／學校政策或受保護的安裝路徑仍可能限制安裝。AI 推論在 Chrome 內；Windows Native Messaging host 只處理本機模型檔案與下載管理。首次模型下載需網路，其後音訊及待翻文字不送往付費 API 或模型供應商。

## 安裝與升級

1. 從本儲存庫的 **Releases** 下載 Setup，或下載安裝 ZIP 後解壓執行 Setup。GitHub 自動產生的 **Source code ZIP 不是安裝包**。
2. 預設安裝位置為 `%USERPROFILE%\LiveLocalTranslator`。
3. 開啟 `chrome://extensions`，開啟開發人員模式，按「載入未封裝項目」，選安裝目錄中的 **extension**；這層直接有 manifest.json。
4. 在擴充功能設定下載／匯入模型，儲存、暖機，再回到直播分頁啟動翻譯。首次使用請先測試較小模型。
5. 聊天室英日機翻：選「Chrome 本機機器翻譯」和「英／日自動」，依提示分兩次點擊準備英文、日文模型，再儲存。

升級沿用原安裝位置，保留 models 與 data。完成後在 Chrome 重新載入擴充功能，重整影片與設定頁。移除工具可選保留模型；Chrome 中的擴充功能須另外移除。

## 預覽版限制

- 未保證句尾後一秒完成；模型大小、字幕與聊天室共用資源會影響速度。
- 2,000 則是接收上限，不是每分鐘全部翻完的承諾；僅處理頁面已載入留言，超量、15 秒過期或推論異常會略過。
- 英日自動是受限的字形分流，不是全語言辨識。純漢字需要 Chrome 已就緒偵測器，不確定則略過；其他拉丁語言可能被當成英文。同一留言英日混寫不保證逐詞翻譯。
- 模型仍可能幻聽、漏譯、誤譯；詞彙表與人聲過濾無法完全消除。Qwen 為中國來源實驗選項，使用前須閱讀並確認設定頁警語。
- YouTube 廣告、DRM、原生子母畫面、網站改版與所有登入聊天室情境尚未完整驗收；延後模式會降低畫面解析度／幀率。
- 程式未主動要求螢幕喚醒，但 Chrome 原生影片播放仍可能阻止螢幕關閉；整機睡眠時不會繼續翻譯。
