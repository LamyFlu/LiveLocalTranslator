本機直播翻譯：安裝、升級與移除

首次安裝 Chrome 擴充功能

  1. 執行 Setup，預設安裝到使用者資料夾下的 LiveLocalTranslator。
  2. 在 Chrome 網址列輸入 chrome://extensions，開啟開發人員模式。
  3. 按「載入未封裝項目」，選取安裝位置下的 extension 資料夾；該層直接包含 manifest.json。
  4. 從拼圖選單釘選本機直播翻譯，開啟設定，確認模型資料夾或匯入相容模型。

安裝器不會繞過 Chrome 的使用者操作。擴充功能身分固定，未來請持續使用同一路徑。

從 Releases 升級

下載新版 Setup，沿用原位置直接升級。安裝器不覆寫 models 與 data。完成後到 Chrome 擴充功能頁按重新載入，再暖機一次。一般停止翻譯仍會保留模型。

移除工具

可從 Windows「已安裝的應用程式」、開始功能表的 Live Local Translator，或安裝目錄的 Uninstall.exe 移除。工具會詢問是否保留模型與資料備份。Chrome 的擴充功能請另外到 chrome://extensions 移除。

模型與設定

models/whisper 放 ONNX Whisper，models/llm 放瀏覽器相容的 LLM。詳見 下載與匯入指南。從舊版搬移會另備份詞庫與設定到 data。尚未刪除的瀏覽器快取可作回復來源。

更換模型

已有模型時，儲存新模型設定會自動停止擷取、釋放舊模型並暖機新模型，不必手動卸載。完成後回直播頁按開始翻譯。第一次或沒有模型常駐時仍需按暖機。詞彙表更新與除錯開關即時套用，不需重載。
