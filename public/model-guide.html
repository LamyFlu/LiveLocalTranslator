模型下載與匯入指南

所有推論在 Chrome 本機執行。不使用付費 API。安裝程式只提供本機檔案橋接。

資料夾與操作

預設位置為你的使用者資料夾下 LiveLocalTranslator\models。可在設定按「開啟模型資料夾」。將檔案放好後，按「重新掃描模型」、選取模型並儲存；手動釋放舊模型再暖機。

models/
  whisper/
    whisper-tiny/
      config.json, generation_config.json, preprocessor_config.json
      tokenizer.json, tokenizer_config.json, special_tokens_map.json
      ...其他該儲存庫的 tokenizer JSON/TXT 檔
      onnx/encoder_model.onnx
      onnx/decoder_model_merged_q4.onnx
    whisper-large-v3-turbo/
      ...該儲存庫的所有 JSON/TXT 設定與 tokenizer 檔
      onnx/encoder_model_fp16.onnx
      onnx/decoder_model_merged_q4.onnx
  llm/
    gemma-4-E2B/gemma-4-E2B-it-web.litertlm
    gemma-4-E4B/gemma-4-E4B-it-web.litertlm

模型資料夾名稱可自訂英數字、點、底線或連字號。不能只改副檔名讓格式相容。安裝與升級不會覆寫 models 內的自備模型。

Whisper：多語 ONNX，非 .en

0.4.3 起：Tiny、Base、Small、Medium、Large-v3 Turbo 均可一鍵下載；首次暖機預設會下載所選缺少模型。設定另有「下載目前 Whisper／LLM」按鈕，可自行開始或續傳。Gemma E2B／E4B 也已補入清單。已下載完整的模型會沿用，不會重複取得；不會下載所有檔位。自訂資料夾仍需手動匯入。請以新版 Setup 升級本機橋接程式後，重新載入擴充功能。

小型選擇：Whisper Tiny、Base、Small。下載所有根目錄 JSON/TXT 設定檔，以及 onnx 子目錄中的 encoder_model.onnx 與 decoder_model_merged_q4.onnx。

Medium 中型檔：Whisper Medium 多語 ONNX。可在設定的一鍵下載選擇 Whisper Medium，約 1.09GB，存於 models/whisper/whisper-medium。手動匯入請下載根目錄 JSON/TXT 設定檔與 onnx/encoder_model_fp16.onnx、onnx/decoder_model_merged_q4.onnx。Medium 解碼層較多，可能比 Large-v3 Turbo 慢，不保證 1 秒辨識；需支援 FP16 的 WebGPU。

16GB 品質組合：Whisper Large-v3 Turbo。下載所有根目錄 JSON/TXT 設定檔，以及 onnx/encoder_model_fp16.onnx 和 onnx/decoder_model_merged_q4.onnx，約 1.61GB 權重。這裡用 FP16 encoder，避免 FP32 大權重與額外 external-data 檔的負擔。需要支援 FP16 的 WebGPU。

不要選英文限定 .en 版本來辨識日文。PyTorch .pt／safetensors 不能直接放進此 ONNX runtime 使用。模型越大不代表延遲一定更低。

LLM：瀏覽器專用 web.litertlm

目前驗證路線使用 Google Gemma 的 LiteRT-LM Web 格式：

  • Gemma 4 E2B：只取 gemma-4-E2B-it-web.litertlm，約 2.01GB。
  • Gemma 4 E4B：只取 gemma-4-E4B-it-web.litertlm，約 2.97GB；用於 16GB 建議組合。

一般桌面版 .litertlm、GGUF、safetensors 不能假設可直接載入本版 Web runtime。不要下載整個儲存庫的所有平台模型。若 Hugging Face 要求同意授權，請自行在該網站完成，再下載相容檔案。

本版另提供下方 WebLLM 引擎與較大模型。不同引擎的格式不可互換，預設與下載清單未加入中國來源模型。

16GB 與保留資料

16GB 建議為 Large-v3 Turbo＋Gemma E4B，這是品質取向的組合。磁碟權重大小不是實際顯存用量，還有 KV cache、運算暫存及影片解碼；不能保證所有 16GB 顯卡與驅動都適用，也不保證辨識在 1 秒內完成。

舊版可用「搬移舊版已下載模型」匯入瀏覽器 Cache API 的模型；同時保存詞庫與設定備份。舊快取先保留作回復。升級沿用固定安裝路徑；移除工具提供保留模型與資料的選項。

較大 LLM：WebLLM MLC 格式

設定的「較大 LLM：一鍵下載」可自動下載固定版本，檔案會放在安裝目錄 models/llm。保持 Chrome 開啟直到完成；可取消並保留進度，下次按下載／續傳即可繼續。下載完成會比對每個檔案的 SHA256，不需 API 金鑰。

顯存估計不是整個程式實際用量，另有 Whisper、影片與暫存。較大不保證較準或較快，日文與繁中品質也有差異。Mistral 7B 本機日文測例有明顯誤譯，僅列實驗，不建議日文直播；E4B 仍為 16GB 預設。12B 已接入；在本機可與 Large-v3 Turbo 常駐，但完整直播字幕尚未達一秒。

下載後選擇對應翻譯引擎，LLM 資料夾維持自動選取，再儲存；已有模型會自動重載與暖機。若要手動放入，需與程式附帶的 model-catalog.json 固定版本一致，包含 mlc-chat-config.json、tensor-cache.json、ndarray-cache.json、tokenizer 檔與所有 params_shard_*.bin；然後按一次下載／續傳來驗證並建立完成標記。一般 GGUF、PyTorch 與 safetensors 無法直接使用。

WebGPU 模型核心隨擴充功能打包，權重留在 models/llm；推論完全在 Chrome，不呼叫本機 AI 伺服器或付費 API。首次模型載入可能需數十秒，與單句翻譯耗時不同。原模型與轉換格式的授權請參閱對應模型頁面。

人聲與來源語言

小型 Silero VAD v5 隨程式打包，在 Chrome 的 WASM 內判斷人聲，不改變播放音質。它可降低音樂與音效造成的 Whisper 幻聽，不能保證完全避免，過嚴也會略過很短的真實語音。除錯可查看人聲分數、RMS 與略過原因。

來源語言可選自動多語或限定英／日，每個片段重新判斷主要語言。這不等於可靠的逐詞英日混說辨識；混合片段可能只留下其中一種語言。自動偵測也會增加耗時，要求低延遲時可固定主要語言。Chrome Translator 目前需固定來源；Gemma 與 WebLLM 可使用自動模式。

Gemma 4 12B（0.3.1）

設定選 LiteRT · Gemma 4 12B，LLM 資料夾維持自動選取。16GB 若遇記憶體不足，先改 Whisper Base／Small 或關閉其他占用 GPU 的分頁。Gemma 2 9B 已從可用清單移除，舊設定會遷移到 12B。

手動匯入請用 litert-community/gemma-4-12B-it-litert-lm 固定 revision 7a0b1ce0ea821bcd01c5f72af84155e02191152f 的 gemma-4-12B-it-gpu.litertlm，放入 models/llm/gemma-4-12B/，再按下載／續傳完成 SHA256 驗證與標記。GPU／Web 檔案雖相同大小，內容雜湊不同，不能任意互換；GGUF、safetensors、桌面完整多模態版本不能直接代替。

刪除與磁碟保護

設定頁模型磁碟空間管理可查看各模型實際大小、確認後刪除完整或部分下載。使用中（含其他設定檔）與下載中會拒絕刪除；先釋放／取消，重新掃描後再刪。刪除永久移除該模型資料夾；詞彙表和 data 保留，需重新下載才能再用。

安裝目錄模式不重複持久化權重；翻譯快取僅 RAM，最多 1000 筆／8MiB；除錯最近 200 句存工作階段記憶體，不錄音。下載前及過程檢查磁碟空間、保留至少 1GiB；錯誤不自動重試，部分下載可續傳。舊版瀏覽器模型快取為保留回復用途，不會自動清除。Chrome／驅動快取、作業系統換頁及溫控仍由系統管理，不能保證零寫入或所有硬體零風險。

0.4.0：Qwen3.5 4B 與 YouTube

新增 Qwen3.5 4B Q4（約 2.39GB，中國供應商來源實驗模型），使用前需閱讀並確認設定頁警語。可能拒譯、改寫敏感內容，本機執行不會移除這些特性。日文人名測例曾只替換名稱、留下日文；字幕已加入偵測與專名標記重試，仍需核對。模型格式為 MLC，請用一鍵下載與雜湊驗證，不能用 GGUF 代替。

YouTube 可選即時播放或 2–10 秒延後同步；延後畫面最高 960×540／15fps，約 192MiB 像素緩衝上限，不新增音訊有損編碼，不寫入錄影。同步最長切段 4 秒，長句可能切開；模型太慢仍會晚到，重模型可試 8–10 秒。聊天共用本機 LLM、字幕優先排隊、預設每分鐘 8 則，原留言下加入譯文，不送出留言。聊天未經所有實站環境驗收。
